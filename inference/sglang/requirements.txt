# Shared client/pip environment for inference/sglang (llm/, embedding/, reranker/), Python 3.12.
# Build one venv at the stack root (inference/sglang/.env_sglang), activate it from any leaf.
#
# AMD / ROCm 7.2 (gfx950) -- ROCm torch FIRST, do not reorder:
#   python3 -m venv .env_sglang && source .env_sglang/bin/activate && pip install -U pip
#   pip install torch==2.11.0 torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
#   pip install --no-deps sglang==0.5.17   # a plain install replaces ROCm torch with a CUDA wheel
#   pip install -r requirements.txt
#   python -c "import torch; print(torch.__version__, torch.version.hip)"   # must still show +rocm7.2
#   # if CUDA torch got pulled in: pip install --force-reinstall --no-deps torch==2.11.0 --index-url https://download.pytorch.org/whl/rocm7.2
# On ROCm this venv cannot serve (sgl_kernel/aiter have no ROCm wheel) -- serve from the vendor
# container documented in README.md and use this venv only for the client scripts.
#
# NVIDIA / CUDA 13 -- this pip route serves all three workloads, no container:
#   python3 -m venv .env_sglang && source .env_sglang/bin/activate && pip install -U pip
#   pip install torch numpy                # -> the current CUDA 13 build
#   unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy  # wheel hosts 403 via proxy
#   pip install "sglang[all]"              # -> sglang 0.5.18, sglang-kernel, flashinfer
#
# Do not install flash-attn on ROCm (CUDA-only wheel); SGLang selects aiter/triton itself.
# Do not `pip install aiter` -- that PyPI project is an unrelated async-iterator library, not
# AMD's AITER, and it shadows the real one.
