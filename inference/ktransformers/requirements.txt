# Client/probe dependencies for inference/ktransformers (Python 3.12) — CPU-GPU
# heterogeneous MoE inference. The engine itself is installed per-vendor, below.
# Venv convention: python3 -m venv .env_ktransformers (at inference/ktransformers/).
#
# NVIDIA / CUDA — prebuilt wheels, full serving path:
#   pip install torch numpy python-dotenv
#   pip install kt-kernel==0.7.0              # AMX/AVX512 CPU variants + CUDA SM80/86/89/90
#   pip install sglang-kt==0.7.0              # kvcache-ai SGLang fork, NOT the official `sglang`
#   pip install nvidia-cudnn-cu12==9.16.0.29  # or set SGLANG_DISABLE_CUDNN_CHECK=1; without
#                                             # it sglang-kt aborts at startup on cuDNN<9.15
#   Unset any host proxy first (a proxy typically 403s pypi.nvidia.com / HF).
#   kt-kernel/sglang-kt pull CUDA torch 2.9.1+cu128 — expected, and fine on a cu130 host.
#   Do not force torch back to cu130: it breaks their pins.
#
# AMD / ROCm — source build required. The PyPI kt-kernel wheel is CUDA-only (statically
# linked cudart, no HIP path) and silently degrades to CPU-only on AMD:
#   pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/rocm7.2   # torch FIRST
#   pip install -r requirements.txt           # this file
#   git clone https://github.com/kvcache-ai/ktransformers $DATA_DIR/ktransformers_src
#   cd $DATA_DIR/ktransformers_src/kt-kernel
#   export CPUINFER_USE_ROCM=1 ROCM_PATH=/opt/rocm PYTORCH_ROCM_ARCH=gfx950
#   export CPUINFER_CPU_INSTRUCT=NATIVE CPUINFER_ENABLE_AMX=OFF
#   pip install . -v --no-build-isolation --no-deps
#
#   --no-deps is required: kt-kernel's pyproject hard-pins torch==2.9.1 + triton and would
#   replace the ROCm torch with a CUDA wheel (ROCm torch ships triton-rocm, which does not
#   satisfy the `triton` name). Re-check torch.version.hip after any pip operation.
#   Verify the build is really HIP-linked:
#     readelf -d $(python -c 'import kt_kernel;print(kt_kernel.kt_kernel_ext.__file__)') | grep NEEDED
#   You want libamdhip64.so.7.
#
#   Serving is blocked on ROCm: sglang-kt hard-pins CUDA-only packages as unconditional
#   requirements. See llm/README.md.
#
# torch is installed per-vendor above and is deliberately not pinned here.
