# Python client dependencies for inference/ollama (Python 3.12)
# (llm/: Qwen3.8-27B Q8_0; embedding/: EmbeddingGemma-300M Q8_0).
#
# Install:
#   python3 -m venv .env_ollama          # at inference/ollama/
#   .env_ollama/bin/pip install -r requirements.txt
#
# The server is not a pip package — it is a container:
#   AMD / ROCm:    docker pull ollama/ollama:rocm    # gfx950 native, no HSA_OVERRIDE_GFX_VERSION
#   NVIDIA / CUDA: docker pull ollama/ollama
#   # if Docker Hub is proxy-blocked, first:
#   unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy
# Run lines, Modelfile registration and env overrides: llm/README.md, embedding/README.md.
#
# Do not use the `-v ollama:...` named volume for the model store: it lands under
# /var/lib/docker on the root filesystem and `ollama create` copies blobs in.
#
# Do not add a TEMPLATE directive to the embedding Modelfile. EmbeddingGemma's task prefixes
# are applied client-side by embedding/inference_embedding_ollama.py, because /api/embed
# sends input through verbatim and a TEMPLATE cannot express different query/document
# prefixes.
