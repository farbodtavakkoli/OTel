# Shared client environment for inference/vllm (all three leaves).
# The vLLM ENGINE runs in the ROCm container documented in README.md -- this venv is
# only for the folder's client scripts hitting the OpenAI-compatible endpoints.
#
#   python3 -m venv .env_vllm && source .env_vllm/bin/activate
#   pip install -r requirements.txt
#
# One shared venv at the stack root (inference/vllm/.env_vllm) serves the llm/, embedding/
# and reranker/ leaves -- build it once here, activate it from any leaf.
#
# Verified on AMD MI355X (ROCm 7.2.4). NVIDIA H100 (CUDA 13.0): the same clients work, and
# the ENGINE also installs natively via pip (verified) -- see below.

# NVIDIA H100 ENGINE (verified: CUDA 13.0, driver 580.173.02) ------------------

#     pip install vllm          # pulls flashinfer + cutlass-dsl[cu13]; torch stays 2.13.0+cu130
#     pip install python-dotenv
