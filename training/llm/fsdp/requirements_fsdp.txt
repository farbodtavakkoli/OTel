#   AMD (ROCm)     pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/rocm7.2
#                  ROCm wheels for 2.11.0 are on the rocm7.2 index (rocm6.4 stops at
#                  2.9.1). This file's pins then resolve unchanged on top of it.
#   Intel (XPU)    pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/xpu
#   NVIDIA (CUDA 13)  pip install torch==2.11.0    # PyPI default wheel, no --index-url
#                  The PyPI wheel for the 2.11.0 pin below is the CUDA 13 build. Add
#                  --index-url https://download.pytorch.org/whl/cu130 if you want the
#                  explicit +cu130 local version tag. Install it before this file, then
#                  re-verify afterwards:
#                    python -c "import torch;print(torch.__version__, torch.version.cuda)"
