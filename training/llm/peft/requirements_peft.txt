# AMD ROCm (PyPI wheels built for ROCm 6.4.4-7.14.0; CDNA gfx90a/gfx942/gfx950
# and current RDNA) and Intel XPU -- the same PyPI package covers all three.
# Verified on MI355X (gfx950, ROCm 7.2.4): this exact plain-PyPI wheel
# bundles the ROCm binaries, auto-selects libbitsandbytes_rocm72.so, and full
# QLoRA training (nf4 + paged_adamw_8bit) runs. No special index or source
# build needed. If the import or kernels fail on an unlisted card, drop
# --load_in_4bit and train plain bf16 LoRA.

# plain-PyPI 0.50.0 wheel ships a libbitsandbytes_cuda130.so and auto-selects it
# (no ROCm .so loaded); quantize/dequantize_4bit round-trips and full QLoRA
# training run on-GPU. On CUDA the QLoRA path "just works" -- no build step.
