# PyTorch Lightning LLM fine-tuning -- deps for train_llm_lightning.py
#
# Install torch first, matched to your accelerator, then the rest (torch 2.11.0 ROCm
# wheels are on the rocm7.2 index; the older rocm6.4 index stops at 2.9.1):
#   NVIDIA (CUDA)      pip install torch==2.11.0
#   AMD (ROCm)         pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/rocm7.2
#   pip install -r requirements_lightning.txt
#
# On ROCm do not install flash-attn (CUDA-only wheel); the sdpa default needs
# nothing extra.
#
# On CUDA 13 the torch==2.11.0 pin resolves to a CUDA 13 build on PyPI, so no --index-url
# is needed. Install it first, then check it survives the requirements pass:
#   pip install torch==2.11.0 numpy
#   pip install -r requirements_lightning.txt
#   python -c "import torch;print(torch.__version__)"   # must still be 2.11.0
# The prebuilt PyPI flash-attn wheel fails to import against that torch (undefined
# symbol in c10 -- ABI mismatch). For flash_attention_2 on CUDA 13, build it from
# source (--no-build-isolation); otherwise stay on --attn_implementation sdpa.
