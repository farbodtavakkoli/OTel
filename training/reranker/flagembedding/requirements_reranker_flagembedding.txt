# Environment for train_reranker_flagembedding.py (BGE / LLM reranker fine-tuning via FlagEmbedding).
# Install into a dedicated venv.
#
# AMD/ROCm (verified on MI355X / ROCm 7.2.4): install the ROCm torch wheel FIRST,
# then this file. If the root filesystem is tight, put the venv outside the repo on a
# larger volume ($DATA_DIR below is that volume):
#   python3 -m venv $DATA_DIR/envs/.env_flagembedding
#   source $DATA_DIR/envs/.env_flagembedding/bin/activate
#   pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/rocm7.2
#   pip install -r requirements_reranker_flagembedding.txt
# torch installs as 2.11.0+rocm7.2 and satisfies the ==2.11.0 pin below.
#
# NVIDIA (CUDA): the default PyPI torch wheels are CUDA builds, so skip the ROCm
# index line:
#   pip install -r requirements_reranker_flagembedding.txt
#   # optional, needs the CUDA toolkit:
#   # pip install flash-attn==2.8.3
#
# NVIDIA H100 / CUDA 13.0 (verified on driver 580.173.02, Python 3.12.3):
# the torch==2.11.0 pin below has NO cu130 wheel, so install torch FIRST and then
# this file WITHOUT the torch line (the plain PyPI wheel is the native CUDA-13 build):
#   pip install torch numpy                       # -> torch 2.13.0+cu130 (CUDA 13.0)
#   grep -v -E '^\s*torch==' requirements_reranker_flagembedding.txt > /tmp/reqs_notorch.txt
#   pip install -r /tmp/reqs_notorch.txt          # keeps transformers==4.57.1 (<5, required)
#   python -c "import torch;print(torch.__version__,torch.version.cuda)"  # RE-VERIFY -> 2.13.0+cu130
# The transformers<5 pin is unchanged on CUDA (same library constraint as ROCm).
# Do NOT install flash-attn on ROCm (CUDA-only build here) — utils.resolve_attn()
# keeps FlagEmbedding's --use_flash_attn False and the model falls back to sdpa.
