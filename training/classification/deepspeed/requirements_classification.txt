# Pinned environment for train_llm_classification.py (Python 3.12).
# Sequence-classification full fine-tuning on HF Transformers + DeepSpeed (ZeRO-2).
#
# AMD/ROCm 7.2 — install the ROCm torch wheel FIRST, then the rest of this file without
# the torch/flash-attn pins:
#   pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/rocm7.2
#   grep -vE '^(flash-attn|torch)==' requirements_classification.txt | grep -vE '^\s*#' | xargs pip install
#
# NVIDIA/CUDA 13 — the torch==2.11.0 pin resolves to a native cu130 wheel on plain PyPI,
# so no --index-url is needed. Install torch first, then the rest of this file without the
# torch/flash-attn lines, then re-verify torch was not clobbered:
#   pip install torch==2.11.0 numpy
#   grep -vE '^(flash-attn|torch)==' requirements_classification.txt | grep -vE '^\s*#' | xargs pip install
#   python -c "import torch;print(torch.__version__, torch.version.cuda)"
#
# deepspeed==0.19.4 installs as a pure-Python wheel on both vendors — no nvcc/hipcc build,
# no DS_BUILD_* flags. flash-attn is optional everywhere and must never be installed on
# AMD (CUDA-only build); train_llm_classification.py auto-falls back to "sdpa".
#
# Use --zero_stage 2: --zero_stage 3 trains fine but silently saves no weights
# (build_deepspeed_config never sets stage3_gather_16bit_weights_on_model_save).
